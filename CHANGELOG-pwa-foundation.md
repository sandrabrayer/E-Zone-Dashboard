# PWA foundation — installability (PR 1 of 2)

Makes the E-Zone Dashboard installable as a Progressive Web App on phones and
desktops ("the phone option" from the ecosystem roadmap), following the same
recipe already shipped for ezone-therapists / outpatient. **Installability and
offline shell only** — the kanban-column and growth-graph mobile redesign is
deliberately out of scope and lands in **PR 2**.

Frontend + a few hand-rolled static routes. **No `Code.gs` change, no Apps
Script deploy.**

## What ships

1. **`public/manifest.json`** — web-app manifest. `name` "E-Zone Dashboard",
   `short_name` "E-Zone", `display: standalone`, `dir: rtl`, `lang: he`,
   `theme_color` + `background_color` `#0b1020` (the app's `--bg`), icons at
   192 / 512 / maskable-512.
2. **Icons** (`public/icons/`) — white letter-**E** on the app green
   (`--success #2dd47a`), generated as PNG at 192×192 and 512×512, plus a
   512×512 **maskable** variant with extra safe-zone padding. Generated by a
   self-contained encoder (built-in `zlib`, no `canvas`/`sharp` dependency).
3. **`public/sw.js`** — service worker with a **versioned** cache name
   (`ezone-dashboard-v1`; bump `CACHE_VERSION` to invalidate). Old caches are
   deleted on `activate`.
4. **`public/index.html`** — manifest link, `theme-color` meta,
   `apple-touch-icon`, `apple-mobile-web-app-capable` (+ title/status-bar
   metas), and a **guarded** SW registration
   (`if ('serviceWorker' in navigator)`, registered on `load`, failures
   non-fatal).
5. **`server.js`** — explicit routes for `/manifest.json`, `/sw.js`, and the
   three icon files. Serving is hand-rolled (no `express.static`), so without
   these the assets would hit the 404 fallback.
6. **`public/style.css`** — minimal responsive fixes only (see below).

## Service-worker caching policy (the important part)

The single rule that protects patient data: **`sw.js` never caches clinical
data.** The decision lives in one pure function, `shouldCache(url)`, exported
for unit testing.

- **NETWORK-ONLY** for any request whose URL contains `"sheets"` or whose path
  contains `/api/`. Patient / lead data is never written to the Cache Storage,
  so an offline device can never surface stale clinical data.
- **NETWORK-FIRST** for the app shell (`/` and `/index.html`). The HTML is
  `__BUILD__`-substituted per deploy (see `sendIndex` in `server.js`), so it
  must never be served stale while online — the cached copy is only an
  **offline fallback**. `shouldCache()` returns `false` for the shell for this
  reason.
- **CACHE-FIRST** for the versioned static assets: `app.js`, `style.css`,
  `manifest.json`, and `/icons/*`. Matched with `ignoreSearch` so
  `app.js?v=__BUILD__` still hits the cache.

Lifecycle: `skipWaiting()` on `install` and `clients.claim()` on `activate`,
so a freshly deployed worker takes over open tabs immediately instead of
waiting for every tab to close.

Note: `server.js` already stamps `no-store` on every response, which is exactly
right for `sw.js` — the worker file itself must not be HTTP-cached, so each
deploy's worker is always re-fetched; the worker then does its own client-side
caching.

## Responsive fixes (minimal — NOT the PR 2 redesign)

Scoped strictly to touch usability; the kanban columns and growth graph are
untouched.

- **Modals fit ≤400px viewports** — `.modal` gains
  `max-width: calc(100vw - 24px)` (+ `max-height` / internal scroll). No change
  to the 440px desktop width.
- **≥44px tap targets on phones** — `@media (max-width: 480px)` sets
  `min-height: 44px` on `.btn` and `.tab` (WCAG 2.5.5 / iOS HIG).
- **Wide tables scroll horizontally** — `.be-table-wrap` /
  `.be-action-plan` get `overflow-x: auto` + momentum scrolling so a wide table
  never forces the page to scroll sideways.

## Tests

`test/pwa-foundation.test.js` (node:test + vm-sandbox, matching
`breakeven-revenue.test.js`):

- `manifest.json` parses as valid JSON and carries the required fields
  (`name`, `short_name`, `display`, `dir`, `lang`, `start_url`, theme/background
  colors) and 192 / 512 / maskable icons whose files exist on disk.
- `sw.js` cache name is versioned and embeds `CACHE_VERSION`.
- `shouldCache(url)` is network-only for `sheets` / `/api/` URLs, network-first
  (not cache-first) for the shell, and cache-first for the versioned static
  assets.

Full suite: **109 passing** (`npm test` → `node --test`).
